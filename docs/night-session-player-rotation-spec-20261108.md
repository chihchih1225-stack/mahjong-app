# 誰與爭鋒｜整晚場次與中途接手（需求已確認）

基準：正式 V182 / 2373269cf5abfe1d29967565f12d14ef9083723d
狀態：開發分支規格，尚未部署

## 已確認流程
1. 首次開局：選四人、抽位、東一開始。
2. 打完一將：保存當將四人的逐把戰績和淨額，但不代表整晚結算。
3. 繼續下一將：可更換一至多名玩家，重新抽位、東一開始；同一晚各玩家金額累計。
4. 今晚結束：總結算列出當晚所有曾上桌玩家（包括已離場者），逐人累加各將淨額；總和必須為 0。
5. 中途接手：設定目前牌局進度、莊家、連莊次數、四人目前輸贏金額；金額必須合計 0；此前未記錄牌局不能虛構胡牌、勝率、徽章等統計。

## 不可破壞
- 既有連打與歷史牌局合併呈現
- 正式 PocketBase 資料及舊戰績
- iPhone 單頁計分、投影、直播
- 原有牌局計分公式與莊家加台
- 不同玩家身份不能因換座位或離場而混淆

## 技術設計待實作驗證
- 使用獨立 nightId 串接多個既有 session，保留每將獨立玩家名單與逐把紀錄。
- 新增每將 openingNets 欄位，用於中途接手；以明確標記區分已知開局餘額與有逐把證據的戰績。
- 當晚總結算為各將 net 的彙總，不可只讀取最後一將 P 陣列。
- 須先檢查 PocketBase schema 是否可存 nightId/openingNets；若不支援，先設計相容方案，不能直接修改正式 DB。
- 若今晚中途刷新或重登，必須能恢復 nightId、累計金額及所有參與者。
- 夜場總結算與每將結束須分離；避免重複計入 openingNets。
- 任何正式發布前先測試 4→5→6 人、離場再回桌、中途接手、重登、歷史統計與金額守恆。

## 驗收
- 4 人首將 + 換第 5 人次將：總結算 5 人且離場者仍列示
- 連續換至第 6 人：總結算 6 人
- 跨將同玩家金額正確相加；所有玩家加總 0
- 中途輸入 +500/-200/-100/-200，後續逐把金額正確累加，未記錄牌局不產生勝負統計
- 舊資料及正式功能不回歸
